# Conversor de Unidades

Aplicacao de terminal em Python para conversoes de comprimento, volume e area.

## Executar

Requer Python 3. Execute na pasta do projeto:

```bash
python3 conversor.py
```

Escolha uma opcao de `a` a `i` e introduza o valor pedido. Os valores decimais usam ponto.

## Conversoes

| Opcao | Conversao |
| --- | --- |
| a | metros para quilometros |
| b | metros para centimetros |
| c | centimetros para metros |
| d | metros para milhas |
| e | milhas para metros |
| f | litros para hectolitros |
| g | hectolitros para litros |
| h | metros quadrados para hectares |
| i | hectares para metros quadrados |
